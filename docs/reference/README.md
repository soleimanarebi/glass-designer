# Reference documents

The engine's data and equations are traced to these documents (see `packages/engine/src/data/sources.ts`
and `docs/calc-spec.md` §9). They are licensed copies and are not committed: keep them in this folder locally.

| Id | Document | File |
| --- | --- | --- |
| EN16612 | BS EN 16612:2019 Glass in building, lateral load resistance by calculation | `BS EN 16612-2019 ….pdf` |
| ISE | IStructE, Structural use of glass in buildings, 2nd ed., 2014 (text extract) and its balustrade chapter | `Structural_use_of_glass_in_buildings_-_IStructe_2nd_Edition_February_2014.pdf.txt`, `IStructE_2014-Balustrades.pdf` |
| BS6180 | BS 6180:2011 Barriers in and about buildings | `BS_6180-2011_….pdf` (1999 edition kept for history) |
| BS6262-4 | BS 6262-4:2018 Glazing for buildings, safety related to human impact | `BS 6262-4-2018-….pdf` |
| REPORT | Example report: Brent Cross Plot 201 glass calculation report | `Brent Cross-201.docx` |
| SHEET | Glass to PR EN 16612 / IStructE 2014 spreadsheet v4.0 | `Glass_to_PR_EN_16612_IStructE_Glass_in_Buildings_2014_v4.0.xlsx` |
| MEPLA-DG | MEPLA help: Double Glazing | `Double_Glazing_-_Mepla_Software_GmbH.pdf` |
| MEPLA-VER | RWTH Aachen verification calculations for SJ MEPLA | `SJ_MEPLA_verification_RWTH_Aachen.pdf` |
| MEPLA-NL | MEPLA help: Non-Linearity | `Non-Linearity_-_Mepla_Software_GmbH.pdf` |

characteristics), MEPLA Pro 2025 brochure and comparison of results.
